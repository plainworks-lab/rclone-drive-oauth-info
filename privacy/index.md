# Privacy Policy

This application is a personal OAuth client used with rclone to access the owner's Google Drive.

## Data Access

The application accesses Google Drive data only when instructed by the owner for personal file operations.

## Data Sharing

Google Drive data is not sold, shared, or transferred to third parties.

## Data Storage

The application does not operate a separate server-side database for storing Google Drive data.

## Purpose

This OAuth client is for personal use only and is used to transfer files between the owner's devices and Google Drive using rclone.

## Contact

For questions regarding this application, please use the developer contact information associated with the Google Cloud OAuth configuration.
